Semanticraft

Transform Markdown into Structured JSON Schemas

A powerful, extensible parser that extracts semantic structure from your markdown documents and converts them into clean, validated JSON schemas.

$ npm install semanticraft
Explore Features Quick Start

Why Semanticraft?

Built for developers who need reliable, extensible markdown parsing with first-class TypeScript support.

Lightning Fast

Optimized parser delivers sub-millisecond processing for documents of any size. Handles 10MB+ files with ease.

Type-Safe

Full TypeScript support with generated types from your schemas. Catch errors at compile time, not runtime.

Extensible

Plugin system for custom parsers, validators, and transformers. Build on top of Semanticraft's core.

CLI & API

Use as a CLI tool for quick conversions or integrate as a library in your Node.js or Deno projects.

Schema Validation

Built-in JSON Schema validation ensures your parsed documents meet expected structures and types.

Zero Dependencies

Minimal footprint with zero runtime dependencies. Small bundle size, faster loads, no supply chain risks.

Quick Start

Parse markdown to JSON in three simple steps

Install the package

# Using npm
npm install semanticraft

# Using yarn
yarn add semanticraft

# Using pnpm
pnpm add semanticraft

Basic usage

import { parse, defineSchema } from 'semanticraft';

const schema = defineSchema({
  title: { type: 'string', required: true },
  version: { type: 'string', pattern: /^\d+\.\d+\.\d+$/ },
  tags: { type: 'array', items: { type: 'string' } }
});

const markdown = `
# My Document

version: 1.0.0

tags:
  - parser
  - markdown
`;

const result = parse(markdown, schema);
console.log(result);

// Output:
// {
//   title: "My Document",
//   version: "1.0.0",
//   tags: ["parser", "markdown"]
// }

Advanced: Custom Transformers

import { parse, defineSchema, transformer } from 'semanticraft';

const customTransformer = transformer({
  date: (value) => new Date(value).toISOString(),
  uppercase: (value) => value.toUpperCase(),
});

const schema = defineSchema({
  created: { type: 'date', transform: customTransformer.date },
  title: { type: 'string', transform: customTransformer.uppercase }
});

const result = parse(`
created: 2024-01-15
title: hello world
`, schema);

console.log(result);
// { created: "2024-01-15T00:00:00.000Z", title: "HELLO WORLD" }

Validation Error Handling

import { parse, defineSchema, ValidationError } from 'semanticraft';

const schema = defineSchema({
  count: { type: 'number', min: 0, max: 100 }
});

try {
  parse('count: 150', schema);
} catch (e) {
  if (e instanceof ValidationError) {
    console.log(e.errors);
    // [{ field: 'count', message: 'Value 150 exceeds maximum of 100' }]
  }
}
